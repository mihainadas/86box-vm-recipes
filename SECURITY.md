# Security policy

## Supported versions

Security fixes apply to the current `main` branch. Older commits and downstream copies are not maintained as separate supported versions.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/mihainadas/86box-vm-recipes/security/advisories/new) for a vulnerability in this repository. Do not open a public issue until a fix or coordinated disclosure is ready.

Describe the affected revision, public component, impact, and minimal reproduction. Replace private paths and media details with placeholders. Never send product keys, operating-system or ROM images, installed disks, credentials, personal data, or other material you cannot redistribute.

This repository contains community recipes and helpers, not the 86Box emulator itself. Report emulator vulnerabilities through the upstream 86Box project's own security or support channels.

You should receive an acknowledgement within seven days. Disclosure timing will be coordinated according to severity, exploitability, and the availability of a tested fix.
